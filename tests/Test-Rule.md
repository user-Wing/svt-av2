# 测试规则

`Sources/Intra` 保存单帧源图；`Sources/Inter` 保存约 15 秒源视频。目标共 100 张：1080p 和 2160p 各 20 张 2D、20 张真人、10 张指定的 Hello World、MyGO、GBC 样本。后一组按本项目约定归入 3D 测试组，记录原作品及来源，不据此判断作品制作形式。每组分辨率必须真实核验，不以文件名代替。现有源必须保留，补足而非重复增加。

源图名 `1080p-2D-01.ext`；编码输出名应同时保留样本编号以避免覆盖，例如 `1080p-2D-01-SVT-p6-V1-93.ext`，其中 V1-93 表示实测 VMAF V1 约 93，并在元数据中记录精确值。其他类型使用 `3D`、`Real`。

`Comparison/Intra/SVT-p6` 与 `Comparison/Intra/AOM-p0` 保存各自码流及配套信息；`Comparison/Inter` 采用同样结构。`rN` 保存第 N 轮 AV2 输出和信息。保留参考源、编码器与版本、参数、分辨率、帧、文件大小、VMAF V1 与 NEG、耗时、工具和模型身份；结果不得伪称已评分。

质量比较覆盖 VMAF V1 93–97，以相同源和匹配质量比较体积，记录采样、插值及共同区间，不外推。优先 V1；当体积减小且 V1 提升幅度大于 NEG 下降幅度时可合入，同时保留两者的原始数值及比较条件。当前六个视频文件中三个源在 `Sources/Inter`，三个既有 SVT 成片在对应对照目录；它们不是六个不同源。

当前 `Sources/Intra/manifest.json` 记录 100 张图的原始路径、抽帧时间或冻结来源、转换及 SHA-256。新抽帧为 10-bit 4:2:0 Y4M；部分 1080p 样本从 2160p 缩小，部分 2160p 资源本身为上游放大版本，不能称为原生 4K 母版。清平乐冻结帧的色彩元数据不完整。3D 测试组只使用 Hello World、MyGO、GBC，不改变作品实际分类。

现有六个文件是三段独立原片及三段对应 SVT 成片，并非六段独立原片；两处视频清单记录探测信息和哈希。新增单帧对照目前覆盖六组的各一张，其余样本尚无完整基准曲线；历史 AOM 测点和 r13 研究候选仅在原始输入 SHA 匹配时复制。实验候选不自动代表已合入基线。旧测试结果按清理要求归入阶段文档，原始输出可能已删除。

1080p 和 2160p 分别使用对应的 V1、NEG 模型，不直接比较跨分辨率的绝对分数。比较必须记录每个模型的身份；一个落在 93–97 区间的测点不能代替完整质量曲线。SVT 新对照为单帧、preset 6、`-g 1`，不代表自动关键帧的完整视频性能。
