## 3. 与 AVM 逐式对齐时确认的关键事实（实现陷阱）

1. `od_ec_prob_scale` 的移位量 = **7**（= `7 - EC_PROB_SHIFT - CDF_SHIFT + 1 + 6`，`CDF_SHIFT=0`）。
2. `av2_prob_inc_tbl` 的 `-1` 填充**必须保留**并以 **signed int** 计算；最后符号会读到该行的 `-1`，
   负偏移靠 unsigned 回绕得到正确边界。
3. tile payload **没有反比特前缀**：AVM `avm_start_encode`/`avm_stop_encode` 直接把
   `avm_od_ec_enc_done()` 的字节写到 offset 0。规范 `init_symbol(sz)` 的 raw bits 就是
   这段流的前 `Min(sz*8,15)` 个 bit，不是独立字段。
4. CDF 数组表示：传 `nsyms` 个上界，省略冗余的尾部 32768；encoder 内部对最后一个符号
   （`s+1 == nsyms`）取 `fh = 0`，与规范 `read_symbol` 的 `f = (symbol==N-1)?0:...` 一致。

## 6. 应用入口（00 决策 (a)）

`Source/Lib/Bitstream/keyframe.{h,c}` 提供单一入口，T001 app 直接调用：

```c
int svt_av2_encode_keyframe_64x64(const uint8_t* y, size_t y_stride,
                                  const uint8_t* u, size_t u_stride,
                                  const uint8_t* v, size_t v_stride,
                                  uint32_t base_q_idx,
                                  uint8_t* out, size_t out_cap, size_t* out_size);
```

- 产完整 Annex B 流：TD + SEQUENCE_HEADER(64x64,L0) + CLOSED_LOOP_KEY(tile_group)。
- 返回 0 成功，负值失败（含 `SvtAv2BitWriterStatus` / `SvtAv2EntropyStatus`）；不会产出截断流。
- 输入平面在 M1 中**被接受但未用于编码**（DC_PRED、零残差），这是文档化行为；
  app 侧写指针即可，无需在残差编码落地后改签名。
- `base_q_idx` 只接受映射到 `COEFF_CDF_Q_CTXS=1`（(90,140]）的值，否则失败，避免 CDF 不匹配。
- 已实测：用 `base_q_idx=100` 产出的流与 `gen.c` **逐字节相同**（21B），
  `avmdec`/`run_matrix --check-bitstream` PASS。
