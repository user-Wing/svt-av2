## 实际实现

新增`--partition-select fixed|adaptive`，默认fixed。adaptive只对完整可见64×64超块按source亮度内容选择保留旧树或四个32×32方叶。四叶通过合法HORZ→VERT/ VERT树编码，叶顺序TL/TR/BL/BR；所有partial超块继续旧边界规则，420色度叶16×16、444色度叶32×32。支持8bit420、10bit420、10bit444和AI/LOW_DELAY_P，可与`--intra-select dc|adaptive`独立组合。

每帧只选择一次计划，Codec持有数组，AI/P core与writer共用同一树和叶顺序。mode、预测、量化系数、内部重建和实际语法对应；容量重试复用结果，不重新选择或重复提交reference。公共配置尾追加partition_selection，参数枚举尾追加SVT_AV2_PARAM_PARTITION_SELECTION；需要使用匹配头文件重新编译，不能与旧M4/M51 DLL混用。

选择代理是父均值SSE与四子均值SSE之差，采用有界uint64整数实现、随位深归一化的固定阈值，严格大于才切分，平局保留旧树。A独立模块模型覆盖阈值和极值，Fraction模型交叉验证实际输入计划。这不是完整RD，未加入更多树型、矩形transform、其他方向工具、preset或FFmpeg参数字典。

精确合同见[分区合同](../m52-partition-contracts.md)，规范和CDF条件见[语法研究](../m52-partition-syntax.md)。固定AV2 v1.0.0规范、验收avmdec和旧M4/M51冻结产物保持只读。独立诊断decoder单独保存在artifacts/m52-b/diagnostic-decoder，基于固定tag 966a7d7cd6fcf60360caf5dc413b2aeeb65e144d。

## 质量与性能边界

tools/measure_m52.py使用已逐帧验收的128×128、1000帧mixed输入，对三格式AI/P的四组合分别串行重复3次，记录wall time中位数、FPS、采样峰值RSS、字节及Y/U/V MSE/PSNR，并再次核对stream/recon指纹。测量时存在后台验收任务竞争，不能视为隔离环境速度结论。仅支持QP100，因此BD-rate=N/A；内容代理或个别样例改善不能推广为普遍压缩收益。M5.3仍需更多内容和完整组合场景的质量/速度/内存评估。

已验收mixed长链中，partition开启/关闭的字节比在420约0.751–0.845，在10bit444约1.647–1.867。该代理只看Y均值结构，未计入色度、符号成本和实际重建失真；444样例明确出现字节增加，因此仍保持默认关闭，不宣称通用压缩收益。下一阶段须结合各平面质量和更多场景评估，不能仅凭420字节下降就升级为默认preset策略。

上述字节比来自相同QP，并非相同质量比较：六例Y PSNR均提高约7.4–9.6dB，444色度约提高2.5–2.8dB。分区开/关wall time中位数比为0.930–1.525，采样峰值RSS约3.75–4.38MiB。完整各平面质量及每次命令、时间、内存采样在measurements/measurements.json；不同工具改变失真和码量，不能把这组单点数据解释为BD-rate或普遍效率结论。

## 使用与复验

在C:\Private\ffmpeg-native\deps-full\AV2\svt-av2执行：

```powershell
.\build\m52-root\Windows\bin\SvtAv2EncApp.exe --input input.y4m --output output.av2 --export-recon internal.yuv --pred-structure low-delay-p --intra-select adaptive --partition-select adaptive
```

设`--pred-structure all-intra`为AI；`--partition-select fixed`关闭本轮工具，`--intra-select dc`关闭方向选择。范围仍为QP100、threads1、8倍数尺寸、最大1920×1080，不扩8bit444或422。此为开发构建，旧dist/M4-ffmpeg-min不自动拥有新功能，尚未接入svtav2-params。

tools/verify_m52.py生成独立内容和Fraction计划，执行四组合编码、固定AVM解码、逐帧SHA、实际M51关闭对照与单点质量测量。tools/build_m52_linux.sh分别构建GCC/Clang/SAN；tools/m52_partition_trace.py核对独立decoder输出；tools/finalize_m52.py只有在全部证据满足后才冻结当前源码与5项app/shared产物。新运行必须使用全新输出目录，不覆盖历史证据。
