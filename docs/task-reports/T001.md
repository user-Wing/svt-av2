## 5. 修复的真实缺陷（T001 归属内）

1. **构建失败**：`svt_av2_enc`（静态）与 `svt_av2_enc_shared`（共享）同名输出，Windows 上共享库导入库 `svt_av2_enc.lib` 与静态库冲突 → `ninja: multiple rules generate lib/svt_av2_enc.lib`。已将共享变体 `OUTPUT_NAME` 改为 `svt_av2_enc_shared`，两者可共存。
2. **Y4M 注释解析错误**：`X` 注释仅跳过首个 token，导致注释中的词被当作未知标签而拒绝（如 `Xcreated by test`）。已改为注释消费至行尾。
3. **采样数静默溢出**：`svt_av2_compute_frame_sample_count` 在大尺寸下 `size_t` 回绕，返回截断值。已对每处乘法与累加做溢出检查，溢出返回 `SVT_AV2_ERROR_INVALID_PARAMETER`。
4. **平面尺寸回绕**：`SVT_AV2_DIV_UP(width, 2)` 在 `width == UINT32_MAX` 时 `+1` 回绕为 0，chroma 平面被算成 0，进而漏检溢出。已改为不产生回绕的向上取整。
