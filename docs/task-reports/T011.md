## 2. 冻结配置与关键数值

按契约 §0/§3/§5 与 00 的裁定：

- 8-bit 4:2:0、单线程、All-Intra；`base_q_idx=100`（CDF q-index 1）；DCT_DCT（`TX_CLASS_2D`）。
- TCQ / parity hiding / FSC-IDTX / IST / CCTX / qmatrix **全部关闭**（`allowTcq=0`）。
- 顶层 `PARTITION_NONE` + 单 SB + BRU inactive：**右/下不完整 SB 不写 partition 符号**；完整 SB 仍写 `do_split=0`。
- Luma `TX_64X64`、chroma `TX_32X32`。
- **系数数目 = `av2_get_max_eob(tx_size)` = `min(w,32)*min(h,32)`** → TX_64X64 = **1024**（不是 4096），TX_32X32 = 1024。
- TX_64X64 的 scan 复用 `default_scan_32x32`（AVM `scan.c:1799-1807` 注释原文：tx64 高频半边置零，故用 tx32 的 scan）。
- `eob_multi_size = txsize_log2_minus4[tx_size]` = {4x4:0, 8x8:2, 16x16:4, 32x32:6, 64x64:6}。
- `txs_ctx` 用**未钳制**尺寸算（64x64 → 4）；coded grid / scan / `bwl` / level 缓冲 stride 用 `av2_get_adjusted_tx_size`（钳到 32）。

## 4. 系数语法实现要点（逐条依据见 `docs\coeff-syntax.md`）

### 4.1 符号序（5.20.7.27）

1. `all_zero`（`txb_skip` / `v_txb_skip`）
2. EOB token：`eob_pt_*`（按 `eob_multi_size` 选 16/32/64/128/256/512/1024 的 CDF）
3. `eob_pt_*_extra`（`L(1)` 当 `eobMultiSize==4`，`L(2)` 当 5/6）
4. `eob_extra` 符号 + `eob_extra_bit`（`L(eobPt-3)`）
5. 幅度 `c = eob-1 ..1`：`coeff_base` / `coeff_base_eob` + `coeff_br`
6. DC 幅度 `c = 0`（单独一块）
7. 符号 `c = eob-1 ..0`，紧接着 `read_quant()` 逃逸

### 4.2 真实上下文（契约 §5 硬要求）

全部使用**实际** q / plane / transform size / 邻居状态，不再用 M1 的定值 ctx：

- `all_zero` ctx：luma 用块尺寸快捷判断 + above/left 邻居；chroma 用 `+6`；V 平面 `+ 3`（U 非零时）。
- `eob_ctx = (plane > 0) ? 2 : 0`。
- `txs_ctx`、`eob_multi_size` 按上表。
- `coeff_base` 用 `txs_ctx × hf_ctx/lf_ctx`（`get_txb_ctx` 二维规则，邻居 `Min(mag,3)`）。
- `coeff_br` 用 `get_br_ctx_2d` / `get_br_lf_ctx`（`plane>0 → Min(mag,3)`；`pos==0 → mag`；否则 `isLf ? mag+7 : mag`）。
- `dc_sign` 用 above/left DC 三项和取号（`<0→1, >0→2, =0→0`）。
- `coeff_br` 出现条件 `level > baseLevels && !(isLf && plane>0)`。

## 9. 偏差与说明

1. **`eob_pt_*_extra` 位宽**按 `eob_multi_size` 而非固定值。T015 早期口头提过 64x64 用 L(2)；逐行核对 AVM `encodetxb.c:651-668` 与规范 p.225 后确认：`eobMultiSize==4 → L(1)`，`5/6 → L(2)`。当前冻结配置 luma/chroma 都是 `eob_multi_size==6`，故走 L(2)，与 T015 说法一致；但实现对 4 也正确。
2. **`txsize_log2_minus4` 修正**：早期误用 `(uint32_t)tx_size` 当 `eob_multi_size`，已按 AVM 表改正（8x8→2 而非 1）。
3. **`br_ctx_2d()` 形参语义修正**：早期传 `is_eob`，规范要 `is_lf`；签名与两处调用点已改。
4. **`read_quant()` 从「拒绝」改为「实现」**：证明其编码方向是可前向的（编码器已知 level），因此不再需要 `ERR_UNSUPPORTED`。§11.1 第 4 点已同步更正（原先写「拒绝」）。
5. 契约 §3 的 64x64 max_eob 数值 00 曾发更正（4096 → 1024），本实现按 **1024**。
