## 固定规范与数值修复

固定规范AV2 v1.0.0 PDF515–519，§7.14.2 qlookup/get_q、§7.14.4 dequant步骤5–8；抽取原文保存在fixed-spec-quant-extract.txt。固定tag966a7d7cd6fcf60360caf5dc413b2aeeb65e144d的quant_common.c139–160给出周期查表与位深MAXQ，decodetxb.c907–928给出20bit level检查和24bit乘积掩码。参考仅只读，未触碰历史decoder副本/固定oracle/spec。

修正如下：

1. qlookup原255上限扩至303；10bit高QP不再取得0 quantizer。25项基础表及周期规则不变，q303=245760，均在int32范围。
2. params初始化由唯一100/148改为有效CQP actual范围，拒绝越界而不静默clamp；DC/AC、YUV仍使用同一actualindex，现有delta/qmatrix/TCQ关闭合同不变。
3. producer level ceiling从人为8191升至固定decoder允许的20bit最大1048575。低QP64TX合法level可能超过8191；超出新上限仍整块预检后原子拒绝，无截断。
4. coefficient绝对值先升int64再取负，消除INT32_MIN的有符号溢出。最大abs输入2147483648、最大reciprocal209715及round相乘远低int64上限。
5. 逆量化先取level绝对值，计算 `abs(level)*quant & 0xffffff`，再round3、除以2^txscale，最后应用符号。旧signed先round在低QP量化值非8倍数时会使负系数偏一，现与规范一致。
6. single-coefficient接口保持返回未clip的decoder-masked值；block路径统一通过dequantize_block应用最终bd+7有符号clip，然后交inverse transform。qcoeff非零并不保证dqcoeff非零，因为规范掩码可能使其回0；零块信号仍依据qcoeff。

Forward仍保留原QP100的确定性round-factor48决策，不要求与AVM encoder的fp factor64决策相同；已删除会使人误以为完全复制encoder forward的说明。Decoder reconstruction必须严格规范一致，两者职责不同。QP100既有表值、阈值和数值锚点全部保持；最终流/重建指纹由00独立对照M52冻结程序，不能只凭模块锚点宣称全回归完成。
