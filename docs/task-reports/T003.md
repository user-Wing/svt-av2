## 1. 目标与范围

## 2. 规范依据（AV2 v1.0.0）

本地固定副本 `docs\spec\AV2_Spec_v1.0.0_20260528_38f28e7.pdf`，SHA256 `E9916F09…B533F`（已与契约 §10 核对一致）。

| 主题 | 条款 | 结论 |
|---|---|---|
| `f(n)` 位序 | §4.11.2 | 无符号 n 位，**最高位先写**（MSB-first） |
| `leb128()` | §4.11.6 | 字节对齐；值 ≤ 2^32−1；≤8 字节；第 8 字节 MSB 必须为 0 |
| OBU 单元 | §5.2.1 | `[obu_header][payload]`，payload 不含 size 字段本身 |

| `trailing_bits(n)` | §5.2.3 | 一个 `1` 后跟 (n−1) 个 `0` |

## 3. 冻结接口（contracts §5 待 00 补录）

头文件即契约：`Source\Lib\Bitstream\bit_writer.h`、`obu_writer.h`。

- **位序**：MSB-first。
- **容量策略**：调用方提供固定缓冲；writer 不分配、不增长。写满返回 `NO_SPACE` 且**不提交部分位**（原子性，含 OBU 整体）。
- **错误返回**：`0`=`SVT_AV2_BW_OK`；负数状态：`NULL/INVALID_ARG/NO_SPACE/UNALIGNED/RANGE/STATE/UNSUPPORTED`。
- **finalize**：要求字节对齐，成功后拒绝再写（`STATE`）。
- **OBU payload 交接**：用 BitWriter 写 payload → `svt_av2_obu_payload_finalize()` → `svt_av2_bit_writer_finalize()` → 交给 `svt_av2_obu_write()` 封装（`leb128(size)+header+payload`）。
- **LEB128**：范围 `[0,2^32−1]`、canonical 最短形式、≤5 字节（对合法值）、字节对齐。
- **uvlc**：`svt_av2_bit_writer_write_uvlc()`（§4.11.3），值域 `[0,2^32−2]`（`SVT_AV2_BIT_WRITER_MAX_UVLC_VALUE`），超限返回 `RANGE`。
- **ns(n)**：`svt_av2_bit_writer_write_ns()`（§4.11.13；契约 §5 记为位写入层原语），`n>=1`、`0<=value<n`，否则 `INVALID_ARG`；实现 `w=FloorLog2(n)+1, m=(1<<w)-n`，`value<m` 写 `w−1` 位，否则写 `value+m` 的 `w` 位。
- **两种结束规则分开**（重要）：
  - `byte_alignment()`（§5.2.4）：补 **0** 到字节边界，已对齐时为 no-op；
  - `trailing_bits(nb)`（§5.2.3）：写 **1** 后跟 nb−1 个 0，nb≥1；已对齐时若要一个完整 trailing 字节，用 `write_trailing_bits_align()`（写 0x80）。
  两者不可互换；trailing bits 由调用方在 payload 末尾**显式**调用，writer 不会对任意 payload 自动追加。
- **OBU 必需组合（M1）**：SEQUENCE_HEADER、TEMPORAL_DELIMITER、**CLOSED_LOOP_KEY(type 4)**、REGULAR_TILE_GROUP、REGULAR_SEF、PADDING；其余 type 返回 `UNSUPPORTED`。`obu_header_extension_flag` 固定 0（M1 子集不支持扩展头）。**CLK 分支由 00 在集成期加入（M1 单帧首帧必须为 CLK），T003 已复核并补单测。**

## 8. 调用示例（T004/T005）

```c
#include "bit_writer.h"
#include "obu_writer.h"

/* 1) Build the OBU payload into a caller-owned buffer. */
uint8_t payload_buf[256];
SvtAv2BitWriter pw;
svt_av2_bit_writer_init(&pw, payload_buf, sizeof(payload_buf));

svt_av2_bit_writer_write_uvlc(&pw, seq_header_id);      /* uvlc() fields ... */
svt_av2_bit_writer_write_bits(&pw, seq_profile_idc, 5u);
/* ... remaining sequence_header_obu() fields ... */
svt_av2_obu_payload_finalize(&pw);                      /* trailing_bits + finalize */
size_t payload_size = svt_av2_bit_writer_bytes_written(&pw);

/* 2) Wrap it as an OBU into the output stream buffer. */
uint8_t stream_buf[512];
SvtAv2BitWriter sw;
svt_av2_bit_writer_init(&sw, stream_buf, sizeof(stream_buf));
svt_av2_obu_write(&sw, SVT_AV2_OBU_SEQUENCE_HEADER, 0u, payload_buf, payload_size);
/* stream_buf now holds: leb128(size) | header | payload */
```

若 sequence header 使用 `byte_alignment()` 而非 trailing bits，则把第 1 步末尾的
`svt_av2_obu_payload_finalize()` 换成 `svt_av2_bit_writer_byte_alignment()` +
`svt_av2_bit_writer_finalize()`。两种结束规则由 T004 依规范条款选定。
