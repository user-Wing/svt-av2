# M5.2 A：完整 SB 的内容分区选择与共享树

日期：2026-10-16。状态：READY_FOR_INTEGRATION。仅属主 9 个生产/测试文件已冻结；M5.2/M5 整体由主窗口独立验收后裁定。

## 有界实现与接口

范围仅完整可见64×64 SB从NONE切为四个32×32 square leaves。数组按SB raster一字节，0旧树、1四叶；partial SB必须0。实际合法二叉树为64square HORZ→两个64×32各VERT→TL/TR/BL/BR四32square，420 UV16、444 UV32。合法语法与精确规范依据由B复核；A只修改共享几何、两核心及各自测试，不修改writer/Codec/public API/CMake/版本或固定AVM/spec。

新增Common接口：

- `svt_av2_partition_select_quads(source, geometry, decisions, capacity)`：只读source Y，输出每SB决策；预检失败不写输出。
- `svt_av2_partition_plan_validate(geometry, decisions, count)`：先完整拒绝容量不足、非法值、partial1、NULL配非0 count及错误SB几何。
- `svt_av2_partition_coded_type_plan(geometry, block, decisions, count, partition, is_implied)`：唯一树决策；先验证计划，原边界规则保持。
- `svt_av2_partition_traverse_coded_plan(geometry, decisions, count, visit, user)`：完整计划先验证，非法输入不调用visit。

原traverse_coded作为NULL/0旧树wrapper保留。两core config尾追加 `const uint8_t* partition_decisions` 和 `size_t partition_decision_count`，遍历消费同一不可变计划；不从source再次选择。Codec持有计划至同步writer返回，writer必须调用同一coded_type_plan；生命周期及API接线归00/B。qcoeff仍随同已选叶按Y/U/V hook复制，系数顺序和recon都使用此遍历。

## 成本数学与界限

每个64square分为四个1024样本象限，sum记作S0..S3，总和S。四均值相对整块均值的精确SSE改善为 `(4*sum(Si*Si)-S*S)/4096`，因此不用均值取整或浮点，直接将uint64 score与 `4096*4096*16 << (2*(bit_depth-8))` 比较。只在严格大于阈值时切分，平局NONE。该固定proxy相当于8bit域16/sample的SSE penalty，10bit输入与阈值都按幅度平方缩放；不是RD或压缩收益保证。

10bit合法样本最大1023，每象限sum≤1047552，总和≤4190208；4*sum(Si²)≤17557843083264，远低uint64上限。Cauchy保证score非负。阈值8bit为268435456、10bit为4294967296。读取使用安全sample_load，支持unaligned u16le与奇数字节stride；不读UV、不读取padding/partial SB区域。
