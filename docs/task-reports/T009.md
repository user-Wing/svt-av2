**这不是 AV1。** AV2 的逆主变换是**直接矩阵乘**（`tx_kernel_dct2_sizeN[INV_TXFM]`，`avm/av2/common/txb_common.c`），不是 AV1 蝶形 IDCT。本模块的 kernel 矩阵逐项转写自该表，并由单测对独立转写再次比对。

## 2. 逆变换（decoder 规定过程，bit-exact）

结构与 AVM `inv_txfm_c()`（`avm/av2/common/idct.c:643-759`）逐字一致：

1. **sqrt2 归一化**（仅当 `log2w+log2h` 为奇数，即 4x8/8x4/4x16/16x4/8x16/16x8）：`round_shift(coeff * NewInvSqrt2=2896, 12)`。32x32(5+5)、64x64(6+6) 均为偶数 -> 不触发。
2. **clamp 到 bd+8 中间位宽**：`[-32768, 32767]`（`idct.c:710`）。
3. **pass1**：`line=height, size=width`，内核连续读、**转置写** `tmp[k*height + j]`，clamp `[-32768, 32767]`。
4. **pass2**：`line=width, size=height`，转置写 `block[f*width + k]`，clamp **`[-256, 255]`**（`col_rng`，`1<<bd`）。
5. **32/64 尺寸**：工作核钳到 `min(32, w/h)`（`idct.c:648-649`），`skipWidth/skipHeight` 恒 0，两遍 32 点核后做 2×2 复制上采样（`idct.c:730-751`）。**64x64 只读前 1024 个 coeff。**

**关键点**：逆 1-D 内核 `dst[o] = sum_k matrix[k*size + o] * src[k]`——取矩阵的**列**（由输出下标索引）。这与正变换取**行**不同。T009 的 `verify_all_sizes.c` 早期误用行形式导致全尺寸 inverse 失配；修正为列形式后全 0。参见 4.2。

**输出是 residual（`int16_t`），范围 `[-256, 255]`，不是 `[0,255]`**；加预测与像素 clip 归 T012。

## 3. 正变换（策略，与 AVM 参考一致）

结构与 `fwd_txfm()`（`avm/av2/encoder/hybrid_fwd_txfm.c:987-1017`）一致：

1. **pass1**：`line=width, size=height`，内核跨步读 `src[k*line]`、连续写。
2. **pass2**：`line=height, size=width`。
3. **sqrt2 归一化**（奇数 log2 和，同上）：`round_shift(coeff * NewSqrt2=5793, 12)`。
4. **64x64**：两遍均用 **64 点核**；pass2 只跑前 32 个 y 频率（`skip_line=32`）且每行只保留前 32 个 x 频率（`zero_line=32`），再 repack 到 32 宽栅格（`:1003-1008`），出口 1024 项。详见 3b。

正变换无 clamp。输入超过 `[-255,255]` 返回 `SVT_AV2_TX_ERR_RANGE`（不静默 clamp）。

**正确性边界声明**：正变换不是规范唯一规定的过程。本次实现"与 AVM 参考正变换 bit-exact"是比"码流合法"更强的性质；单测**不**把 `forward + inverse == 源残差` 作为判据。

## 3b. 32x32 / 64x64：正逆**不同构**（本轮关键发现）

00 的 (A) 裁决书 §五.1 曾描述"64x64 只是 32x32 核 + 2× 复制"。该描述**只对逆变换成立**：

| | 逆（`idct.c:643-759`） | 正（`hybrid_fwd_txfm.c:948-1016`） |
|---|---|---|
| 工作尺寸 | `width = height = min(MAX_TX_SIZE>>1=32, 64) = **32**`（`:648-649`） | `width = height = tx_size_wide[TX_64X64] = **64**`（`:952-953`，**无 min**） |
| skip | `skipWidth = skipHeight = **0**`（`:687-688`） | `skipWidth = skipHeight = 64-32 = **32 ≠ 0**`（`:984-985`） |
| 内核 | **32 点核**（`:724-728`）+ 2×2 复制上采样（`:730-751`） | **64 点核**（`:939` case 4 -> `fwd_txfm_dct2_size64_c`） |
| 高半部 | 不涉及（工作区就是 32x32） | 频率 32..63 被 `zero_line` 丢弃（`:353-359`），再 repack 到前 32x32（`:1003-1008`） |
| 入口/出口数目 | 只读 `AVMMIN(1024, w*h) = **1024**`（`:705,708`） | 出口 = **1024** |

因此本模块：**逆 = 32 核两遍 + 2×2 复制；正 = 真 64 点核两遍 + 高半部置零 + repack**。
DCT-II 的 N 点与 N/2 点**不同构**（频率分辨率不同），故正变换**不能**用"32 核 + 复制"实现——这一点已用
`verify_32_64.c` 的双路参考（矩阵式 + AVM 蝶形式）独立证实。

`tx_scale`（`idct.c:761-765`）：TX_32X32 = 1，TX_64X64 = 2；`sqrt2` 归一化用**真实** `log2`（64x64 的 6+6 为偶）-> 不触发。

## 5. 尺度 / 舍入 / 边界（对 T010/T011 冻结）

完整表见 `docs/task-reports/T009-scales.md`。要点：

- `tx_scale = (pels>256) + (pels>1024)`（`idct.c:761`）== `log_scale`（`encodemb.c:819`）。
  ≤16x16 全 `pels<=256 → tx_scale=0`（**16x16=256 不 >256，故为 0**）；**TX_32X32 = 1**；**TX_64X64 = 2**。
- 正变换出口不做 `>> tx_scale` 降尺度（AVM fwd_txfm() 出口亦然）；降尺度由**量化器**完成（encodemb.c:376 正量化、decodetxb.c:526/673 反量化）。≤16x16 出口等价 Q3；32x32 为 Q2；64x64 为 Q1。
- 舍入：`svt_av2_tx_round_shift(v,b) = (v + (1<<(b-1))) >> b`，**算术右移（floor）**，负数不是 round-half-away-from-zero。单测同时钉正负号。
- coeff 布局：raster 行主 `coeff[y*width+x]`，index 0 = DC（对 T010/T011/T012 冻结）。
  **长度**（00 裁决 (甲) 的一般式）：`svt_av2_tx_coeff_count(w,h) = min(w,32) * min(h,32)` == `av2_get_max_eob`。
  即 **TX_64X64 出口仅 1024 项**（**不是 4096**），TX_32X32 = 1024，`w,h<=32` 时即 `w*h`。
- 1-D kernel **不支持原地调用**（`src==dst`）；调用方需分离缓冲。
- **coeff 幅度与量化余量**（T010 实测 + T009 独立复算，全 11 几何，详见 `T009-scales.md` §5b）：
  `max|coeff|` 在 16x16 / 32x32 / 64x64 上**恒为 32640**（从 16x16 起不再增长，因 64x64 pass-2 只跑 32 行）；
  量化余量单调变薄 **22.1x -> 11.0x -> 5.5x**，**禁止把 ≤16x16 的 22x 向上外推**；
  `LEVEL_OVERFLOW` 在 `residual ∈ [-255,255]` 下不可达（最坏 `max|level| = 1483 << 8191`）。
  T009 侧独立复算脚本：`artifacts/T009/verify_coeff_amp_32_64.c`（不读 T010 文件，含结构性断言）。
