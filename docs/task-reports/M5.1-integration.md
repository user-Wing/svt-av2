### 模式证据不只看编码器日志

B的独立固定tag诊断decoder实际读取语法，Python按已完成块的4×4地图重建邻居和61项模式列表。10bit420 P directional例子的P帧实际出现23V/1H/2DC，下一P帧24H/2DC，并有inter混合；不是只在首key开启新模式。诊断raw和不可变验收decoder分别与预先生成的内部recon核对。记录`artifacts/m5-b/mode-trace-matrix.json`；self-test包含错误Y index和UV context的负例。

### 公共API与反例

新增`test_m5_api`覆盖三格式AI/P：参数set/get/init、非法值不修改配置、初始化后参数拒绝、奇数字节stride/非对齐u16le、输入所有权、pending时新输入/EOS拒绝、重复容量不足不写输出、required size一致、重试与无重试双handle流/recon相同、负PTS与INT32_MAX、EOS无多余包。

A审阅发现原输入所有权测试可能因两handle同时读取被覆写缓冲而假通过，已改为控制handle先编码原输入、试验handle发送后覆写再编码。容量重试后下一帧的流/recon一致性同时约束reference只提交一次。A直接core单测另有三格式真实V/H与inter混合、非零系数、方向缺失与平局，1602 checks/0 failures。

## 性能与质量边界

`measurements/measurements.json`记录三格式AI/P的128×128、1000帧mixed素材，off/on各串行重复3次，给出wall time中位数、FPS、采样峰值RSS、完整字节与Y/U/V PSNR/MSE，输出指纹均与已解码验证的长链相同。测量来自本机运行，期间部分测试任务仍在后台；不视为隔离环境的速度结论。当前单QP100，BD-rate=N/A；不能把SAD更低或某个样例字节更少推广成普遍压缩收益。M5.3仍须做更完整场景和组合工具测量。

该mixed素材的on/off字节比约1.000–1.002，耗时比约1.002–1.089，采样峰值RSS约3.7–4.3MiB；没有观察到该素材上的普遍码率收益。当前成果是合法候选工具及有界选择，后续RD/搜索策略才能系统权衡符号成本与失真，不能先宣称preset收益。

## 使用

在`C:\Private\ffmpeg-native\deps-full\AV2\svt-av2`：

```powershell
.\build\m51-root\Windows\bin\SvtAv2EncApp.exe --input input.y4m --output output.av2 --export-recon internal.yuv --pred-structure low-delay-p --intra-select adaptive
```

设`--pred-structure all-intra`为AI；省略`--intra-select`或设`dc`恢复旧行为。仍限8-bit420、10-bit420/444、QP100、threads1、8倍数尺寸且宽≤1920高≤1080。此为开发构建；旧M4最小FFmpeg包不自动拥有新开关，公共config仍需使用匹配头文件重编，不能凭相同版本字符串推断ABI兼容。
